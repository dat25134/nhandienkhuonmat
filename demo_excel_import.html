📊 Demo: Chức năng Import Excel

✅ Tính năng đã hoàn thành

  • Download Template: Tải file Excel mẫu với định dạng chuẩn
  • Import Excel: Upload và xử lý file Excel để thêm khách hàng loạt
  • Validation: Kiểm tra dữ liệu, trùng lặp, và báo lỗi chi tiết
  • UI/UX: Giao diện thân thiện với progress indicator

📋 Cấu trúc Template Excel

File template bao gồm các cột sau:

Cột Tên cột Bắt buộc Mô tả
A STT ❌ Số thứ tự (tự động)
B Họ và tên ✅ Tên đầy đủ của khách
C Số điện thoại ✅ Số điện thoại (không trùng lặp)
D Giới tính ❌ Nam, Nữ, hoặc Khác
E Công ty ❌ Tên công ty
F Bộ phận ❌ Bộ phận làm việc
G Vị trí ❌ Chức vụ
H Ghi chú ❌ Ghi chú thêm

🚀 Cách sử dụng

Bước 1: Truy cập màn hình /manage
Bước 2: Click button "Tải template Excel"
📥 File template_khach_moi.xlsx sẽ được tải về
Bước 3: Mở file Excel và điền thông tin khách
✅ Điền ít nhất: Họ và tên + Số điện thoại
✅ Các cột khác có thể để trống
✅ Lưu file sau khi hoàn thành
Bước 4: Upload file Excel lên hệ thống
📤 Chọn file Excel (.xlsx hoặc .xls)
📤 Click "Import Excel"
📤 Chờ xử lý và xem kết quả
Bước 5: Cập nhật ảnh cho từng khách
🖼️ Click "Sửa" bên cạnh khách cần thêm ảnh
🖼️ Upload ảnh training (1-5 ảnh)
🖼️ Lưu để hoàn tất

⚠️ Lưu ý quan trọng

  • Định dạng file: Chỉ hỗ trợ .xlsx và .xls
  • Dữ liệu bắt buộc: Họ tên và số điện thoại
  • Trùng lặp: Số điện thoại không được trùng
  • Ảnh: Sẽ được thêm sau khi import thành công
  • Lỗi: Hệ thống sẽ báo chi tiết các lỗi gặp phải

🔧 Tính năng kỹ thuật

Frontend (JavaScript):

// Download template
downloadTemplate() {
  const link = document.createElement('a');
  link.href = '/api/excel/template';
  link.download = 'template_khach_moi.xlsx';
  link.click();
}

// Import Excel
async importExcel() {
  const formData = new FormData();
  formData.append('file', file);

📊 Kết quả mong đợi

Sau khi import thành công:

  • ✅ Hiển thị số lượng khách đã thêm
  • ✅ Hiển thị số khách bị bỏ qua (nếu có)
  • ✅ Danh sách khách được cập nhật ngay lập tức
  • ✅ Có thể chỉnh sửa thông tin từng khách
  • ✅ Có thể thêm ảnh training cho từng khách

🎯 Lợi ích

  • Tiết kiệm thời gian: Import hàng loạt thay vì nhập từng người
  • Chuẩn hóa dữ liệu: Template đảm bảo định dạng đúng
  • Xử lý lỗi thông minh: Báo cáo chi tiết các vấn đề
  • Linh hoạt: Có thể bỏ qua các cột không cần thiết
  • An toàn: Kiểm tra trùng lặp và validation
